프로젝트를 열고, 휴대폰에서 여권 OCR 앱을 실행하는 가장 쉬운 순서입니다.

이 문서의 목표: APK 파일을 만들거나 배포하는 것이 아닙니다. 내 휴대폰에 개발용 앱을 설치해 카메라 화면을 확인하는 방법입니다.

Flutter가 보이지 않으면 실행 구성을 만들기 전에 플러그인부터 설치합니다.

1. 휴대폰 준비

1
휴대폰에서 USB 디버깅 켜기

휴대폰의 설정 > 휴대전화 정보 > 소프트웨어 정보로 들어가서 빌드 번호를 7번 누릅니다. 비밀번호를 입력한 뒤, 설정으로 돌아가 개발자 옵션 > USB 디버깅을 켭니다.

2
USB 케이블 연결

휴대폰 잠금을 풀고 PC와 연결합니다. 휴대폰에 “USB 디버깅을 허용할까요?”가 나오면 허용을 누릅니다. 가능하면 “이 컴퓨터에서 항상 허용”도 체크합니다.

권장: 이 앱은 카메라를 사용하므로 에뮬레이터보다 실제 휴대폰으로 확인하세요.

2. 프로젝트 열기

1
Android Studio를 엽니다

시작 화면에서는 Open, 다른 프로젝트가 열려 있다면 File > Open을 누릅니다.

2
아래 폴더를 선택합니다C:\WorkSpaces_Codex\passport-reader-mobile

주의: android 폴더만 열지 마세요. 반드시 passport-reader-mobile 전체 폴더를 엽니다.

3
기다립니다

아래쪽에 Loading, Getting dependencies, Indexing 같은 문구가 보이면 끝날 때까지 기다립니다. 첫 실행은 시간이 걸릴 수 있습니다.

3. lib > main.dart 찾기

왼쪽에 파일 목록이 안 보이거나 lib가 보이지 않으면 아래 순서대로 합니다.

1
파일 목록 창 열기

맨 위 메뉴에서 View > Tool Windows > Project를 누릅니다.

2
표시 방식을 Project로 바꾸기

왼쪽 파일 목록의 맨 위에서 Android ▼를 클릭하고, 목록에서 Project를 선택합니다.

3
main.dart 열기

프로젝트 이름 왼쪽의 작은 화살표를 눌러 폴더를 펼칩니다.

passport-reader-mobile ├─ android ├─ documents ├─ lib │ └─ main.dart ← 이것을 두 번 클릭 └─ test

4. Flutter가 있는지 확인하기

Android Studio의 맨 위 메뉴에서 다음을 누릅니다.

Run > Edit Configurations...

Flutter가 보이는 경우

아래의 “5. 실행 구성 만들기”로 갑니다.

정상 상태입니다.

Flutter가 보이지 않는 경우

Flutter 플러그인이 없거나 꺼진 상태입니다.

아래의 “6. Flutter 플러그인 설치”로 갑니다.

5. Flutter가 있을 때: 실행 구성 만들기

1
새 실행 구성 추가

Run > Edit Configurations... 창에서 왼쪽 위의 + 버튼을 누른 뒤 Flutter를 선택합니다.

2
실행 파일 선택

Dart entrypoint 입력칸 오른쪽의 폴더 아이콘을 누릅니다. 프로젝트 안의 lib > main.dart를 선택합니다.

C:\WorkSpaces_Codex\passport-reader-mobile\lib\main.dart
3
저장

Apply를 누르고 OK를 누릅니다. Android Studio 상단에 main.dart 또는 passport_reader_mobile가 보이면 성공입니다.

대안: lib/main.dart 코드의 void main() 왼쪽에 초록색 ▶가 보인다면, 그 버튼을 눌러 Run 'main.dart'를 선택해도 됩니다.

6. Flutter가 없을 때: 플러그인 설치

1
설정 열기

File > Settings > Plugins를 누릅니다.

2
Flutter 검색

위쪽의 Marketplace 탭을 누르고, 검색창에 Flutter를 입력합니다.

3
설치와 재시작

Install을 누릅니다. Dart 플러그인 설치 안내가 나오면 함께 설치합니다. 설치가 끝나면 Restart IDE를 눌러 Android Studio를 다시 시작합니다.

Enable 버튼이 보이는 경우: 이미 Flutter 플러그인이 설치되어 있으나 꺼진 상태입니다. Enable을 누르고 Android Studio를 재시작합니다.

7. 앱 실행하기

1
상단에서 두 가지를 확인

첫 번째 선택 상자에는 main.dart 또는 passport_reader_mobile, 두 번째 선택 상자에는 연결한 휴대폰 모델명이 보여야 합니다.

2
▶ Run 버튼 클릭

초록색 ▶ 버튼을 누릅니다. 처음에는 앱 설치 때문에 기다리는 시간이 필요합니다.

3
휴대폰에서 카메라 권한 허용

앱이 열리면 카메라 권한 안내에서 허용을 누릅니다. 여권 사진면 전체와 하단 MRZ 두 줄이 녹색 프레임 안에 보이도록 맞춥니다.

8. 문제 해결

문제먼저 할 일
▶ Run 버튼이 회색실행 구성에 main.dart가 선택되었는지 확인합니다. 선택되지 않았다면 5단계를 다시 합니다.
Flutter 항목이 없음6단계대로 Flutter 플러그인을 설치 또는 활성화합니다.
휴대폰 이름이 안 보임USB 디버깅, 휴대폰 잠금 해제, “이 컴퓨터 허용” 창, 데이터 전송 가능한 케이블을 확인합니다.
카메라가 검은 화면휴대폰 설정에서 앱의 카메라 권한을 허용했는지 확인합니다.
처음 실행이 오래 걸림처음에는 도구와 의존성 준비가 필요할 수 있습니다. 아래쪽 진행 상태가 끝날 때까지 기다립니다.

9. 꼭 기억할 점

  • 프로젝트 루트 폴더를 엽니다. android 폴더만 열지 않습니다.
  • 휴대폰 선택과 실행 파일 선택은 서로 다른 일입니다.
  • 앱 실행은 APK 배포가 아닙니다. 내 휴대폰에 개발용 앱을 임시 설치하는 과정입니다.
  • 여권 정보는 민감합니다. 실제 여권 화면을 캡처하거나 외부에 공유하지 마세요.
