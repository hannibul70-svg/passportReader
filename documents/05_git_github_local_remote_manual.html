GitHub와 로컬 Git 저장소 연결 매뉴얼

1. 핵심 개념

구분의미
GitHub 저장소인터넷에 있는 원격 보관함입니다.
로컬 Git 저장소내 PC 프로젝트 폴더의 .git 폴더입니다.
git push내 PC의 커밋을 GitHub로 업로드합니다.
git pullGitHub의 변경사항을 내 PC에 반영합니다.
내 PC 프로젝트 폴더
├─ 소스 코드
├─ documents
└─ .git                ← 로컬 Git 저장소
       │
       │ git push / git pull
       ▼
GitHub 원격 저장소

2. 기존 PC 프로젝트를 GitHub에 처음 연결

GitHub에서 빈 저장소를 먼저 만들고, PC에 이미 프로젝트 폴더가 있는 경우 사용합니다.

cd C:\WorkSpaces_Codex\프로젝트폴더

git init
git branch -M main
git remote add origin https://github.com/계정명/저장소명.git

git add .
git commit -m "feat: initial commit"
git push -u origin main

확인 명령:

git status
git remote -v
git log -1 --oneline

3. 다른 PC에서 프로젝트 이어서 작업

다른 PC에는 git clone을 사용합니다. 이미 복제한 폴더에서 git init을 다시 실행하지 않습니다.

cd C:\WorkSpaces_Codex
git clone https://github.com/계정명/저장소명.git
cd 저장소명

4. 일상적인 작업 순서

git status
git add .
git commit -m "feat: 변경 내용 설명"
git push

작업 시작 전 다른 사람이 변경했을 수 있다면 먼저 git pull --rebase를 실행합니다.

5. 주의사항

커밋 금지: 비밀번호, API 키, 인증서, 개인키, .env, 서명 파일, 운영 데이터. 이 파일들은 .gitignore에 추가합니다.
  • GitHub 저장소 생성만으로 PC 폴더가 자동으로 Git 저장소가 되지는 않습니다.
  • fatal: not a git repository는 현재 폴더에 .git이 없다는 뜻입니다.
  • GitHub에 README를 먼저 만들고 로컬에도 독립 커밋을 만들면 이력이 갈라질 수 있습니다.

6. 빠른 선택표

상황명령
PC에 기존 프로젝트가 있고 GitHub는 비어 있음git init → git remote add origin → 커밋·푸시
새 PC에서 GitHub 프로젝트를 받음git clone
현재 연결 상태 확인git remote -v
변경사항 확인git status
