2. MVP 저장·서버 연동 정책

권장안은 앱 메모리 일시 처리입니다. 여권번호, 생년월일, 얼굴 사진, MRZ는 앱이 열려 있는 동안에만 메모리에 두고, 취소·뒤로가기·삭제·앱 종료 시 제거합니다.

  • 서버 전송 없음
  • 휴대폰 파일·사진첩·데이터베이스 저장 없음
  • OCR 원문·MRZ·사진·NFC APDU 로그 기록 없음
  • 이전 촬영 결과 재조회 없음
선택지설명MVP
A. 앱 메모리 일시 처리앱 실행 중 확인만 가능, 종료 시 삭제채택 권장
B. 기기 암호화 저장재조회 가능, 삭제·분실·백업 정책 필요미적용
C. 서버 전송·저장업무 연계 가능, 동의·암호화·접근제어·보유기간 필요미적용

3. 1차 Flutter OCR MVP 범위

  1. Android/iOS Flutter 앱 골격과 카메라 권한
  2. 여권 데이터면·MRZ 가이드 창
  3. 흐림·반사광·기울어짐·MRZ 미검출 안내
  4. 기기 내 OCR 및 MRZ TD3 체크섬 검증
  5. 인적사항, 사진 영역, MRZ 원문 결과 화면
  6. 취소·재촬영·오류 안내와 메모리 데이터 제거

NFC 칩 읽기는 구현하지 않습니다. 1차 MVP에서는 NFC 버튼을 숨기는 방안을 권장합니다.

4. 3롤 하네스

역할책임파일 수정
Coordinator요구사항, 범위, 완료 기준, 승인 경계없음
BuilderFlutter OCR 구현, 테스트, 문서 갱신있음
Verifier독립 검증, 개인정보 비저장, 회귀 확인없음

순서: Coordinator → Builder → Verifier → Coordinator

5. NFC 2차 착수 조건

  • Android 실제 기기에서 앱 설치·기동·OCR 테스트 통과
  • iPhone 실제 기기에서 앱 설치·기동·OCR 테스트 통과
  • 카메라 가이드, 촬영, MRZ 검증, 결과 화면 테스트 통과
  • 취소 또는 앱 종료 뒤 여권 정보와 사진이 남지 않음 확인
  • Verifier 독립 검증 통과와 Coordinator 완료 확인

6. 검토 필요 항목

  1. 초기 지원 범위를 한국 여권으로 제한할지
  2. 얼굴 사진 영역을 단순 표시만 할지, 품질 평가까지 할지
  3. OCR 단계에서 NFC 버튼을 숨길지, 준비 중으로 표시할지
  4. 실제 여권·승인된 테스트 문서·테스트 기기 목록
