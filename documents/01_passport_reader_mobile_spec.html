여권 OCR 및 전자여권 NFC 판독 모바일 앱 명세

초안 · 2026-10-01
본 문서의 NEC는 NFC를 의미하는 것으로 해석합니다.

1. 목적과 전제

Android와 iOS에서 동작하는 하이브리드 앱으로, 카메라에서 여권의 시각 정보와 MRZ를 인식하고 NFC로 전자여권 칩 정보를 읽어 비교·확인합니다. MVP는 서버 전송이나 영구 저장 없이 앱에서 일시적으로 확인하는 흐름을 기준으로 합니다.

2. 핵심 기능

기능설명
카메라 가이드여권 데이터면과 MRZ가 들어오는 프레임, 흐림·반사광·기울어짐 안내
OCR/MRZ인적사항, 여권번호, 만료일, MRZ 인식과 체크섬 검증
카메라 결과OCR 인적사항, 추출 사진, MRZ 원문, 검증 상태 표시
NFC 판독휴대폰 접촉 안내, BAC/PACE 인증, DG1·DG2 데이터 읽기
전자여권 결과칩 인적사항, 전자여권 사진, 카메라 OCR과의 일치·불일치 표시

3. 사용자 흐름

카메라 촬영
  → 품질 검사 및 OCR/MRZ 인식
  → 카메라 결과 확인
  → 전자여권 NFC 읽기
  → NFC 연결·보안 인증·칩 데이터 읽기
  → 전자여권 결과 및 카메라 결과 비교

NFC 화면은 NFC 감지 → 보안 인증 → DG1 읽기 → DG2 읽기 → 검증 단계를 보여주고, 취소·재시도를 제공합니다.

4. 기술 구조

계층역할
하이브리드 UIFlutter 또는 React Native로 카메라, 화면, 상태 관리 구현
OCR/MRZ기기 내 문서·텍스트 인식, MRZ 파서, 체크섬 검증
Android NFCIsoDep 기반 ISO 14443-4 APDU 통신
iOS NFCCore NFC ISO 7816 태그 세션, entitlement 및 AID 설정
전자여권EF.COM, DG1, DG2, SOD, BAC/PACE, 선택적 Chip Authentication

UI와 공통 업무 로직은 하이브리드로 구현하되, NFC APDU 통신은 각 플랫폼의 네이티브 모듈로 구현합니다.

4.2 권장 기술 스택

영역권장 기술적용 기준
하이브리드 앱Flutter (Dart)단일 UI 코드베이스와 카메라 오버레이에 적합합니다. TypeScript 팀은 React Native를 대안으로 선택할 수 있습니다.
상태 관리Riverpod 또는 Bloc카메라·NFC의 비동기 단계, 오류, 재시도 상태를 관리합니다.
카메라Flutter camera + 플랫폼 API실시간 프리뷰, 가이드 프레임, 자동 촬영 품질 검사에 사용합니다.
OCR/MRZGoogle ML Kit + 자체 MRZ 파서기기 내 텍스트 인식과 ICAO TD3 체크섬 검증을 수행합니다.
Android NFCKotlin + IsoDepISO 14443-4, ISO-DEP APDU 통신과 NFC 권한을 처리합니다.
iOS NFCSwift + Core NFCNFCTagReaderSession, NFCISO7816Tag, entitlement 및 AID 설정을 처리합니다.
전자여권eMRTD 라이브러리 또는 네이티브 모듈BAC/PACE, LDS, DG1, DG2, SOD를 처리하며 라이선스와 호환성을 사전 검토합니다.
사진 디코딩JPEG/JPEG2000 지원 모듈DG2 이미지 포맷 차이에 대응합니다.
보안 저장소iOS Keychain / Android Keystore장기 보관이 승인된 경우에만 암호화 키와 최소 메타데이터를 보관합니다.

5. NFC 전자여권 처리

  1. 카메라에서 읽은 여권번호·생년월일·만료일 MRZ를 검증합니다.
  2. NFC 세션을 시작하고 휴대폰을 여권에 접촉하도록 안내합니다.
  3. BAC 또는 PACE로 보안 인증한 뒤 DG1과 DG2를 읽습니다.
  4. DG1 인적사항, DG2 사진을 표시하고 OCR 결과와 비교합니다.
  5. 후속 단계에서 SOD 및 CSCA 인증서 기반 전자서명 검증을 추가합니다.

6. 개인정보 및 보안

  • 여권번호, 생년월일, MRZ, 얼굴 사진, 칩 데이터는 민감한 개인정보로 취급합니다.
  • 처리 목적·저장·전송 여부를 사용자에게 명확히 알리고 동의를 받습니다.
  • 기본값은 메모리 내 일시 처리이며, 화면 종료 또는 삭제 시 데이터를 제거합니다.
  • OCR 원문, MRZ, APDU, 사진을 로그에 기록하지 않습니다.
